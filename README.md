# 黄油关注提示 · huangyou-watcher

> 一个本地运行的"关注列表 + 更新聚合"小工具。
> 让你不打开 DLsite、不刷 X 时间线,也能第一时间知道关注的 H 游戏 / 画师 / 3D 作者有什么新动静。

## 这是什么

平时关注了一些做黄油(H 游戏)、画特色插图、做特色视频的作者,但:

- **DLsite 的关注邮件**基本进垃圾箱,一个月难得看一次;
- **在 X 上关注他们**又会污染推荐流——你希望时间线大部分还是 AI、科技等内容,偶尔刷到这些作者点个赞就行,不能天天刷到;
- 不同作者散落在 **X / Steam / DLsite** 三个平台,挨个打开太麻烦。

这个工具把你想关注的游戏/作者维护成**一张本地表格**,双击一个按钮,自动去三个平台拉最新动态,汇总成一页报告:有更新就弹窗提醒,报告里能看图、看视频、按分类筛、打星评分、标记已读。

**核心设计:X 拉取走公开时间线,不需要关注、不点赞、不互动——你的 X 推荐流零污染。**

| 弹窗提醒 | 重要事件才弹通知(可按类型/来源/作品控制),并自动打开 HTML 报告 |

| 更新媒体 | 每条 X 新帖的图片/视频直接内嵌显示在报告里 |

| 排序 | 默认顺序 / 关注度(打星)/ 更新频率(近30天) 三种排序 |
| 关注度评分 | 每个卡片 5 颗星,点星即写回表格,按期待程度排序 |
| 已读标记 | 未读高亮琥珀色、已读变灰,状态存浏览器本地,重新生成报告不丢 |
| 取消关注 | 一键移除,自动备份到 `unfollowed.csv` 可反悔 |
| 批量添加 | 报告页大输入框,逗号分隔一次粘贴多个链接,后台自动入库 |
| AI 分类 | 添加时自动给作者打类型标签(游戏/插画/3D/卖肉/视频/其他) |
| 模型可换 | 页面配置任意 OpenAI 兼容 API(本地 Ollama/opencode/云 API 都行) |

### 作品档案与证据(REQUIREMENTS P0+P1)

| 需求 | 功能 |
|---|---|
| FR-01 输入识别 | 四类输入(X帖子/X主页/Steam页/DLsite页)自动识别;解析失败的原链接+原因保留在报告"未识别的输入"区,不再静默丢弃 |
| FR-02 证据提取 | 从 X 帖子/简介提取官方外链、作品名、作者名;**转发/回复里的链接只进候选,不当作作者作品** |
| FR-03 候选确认 | 匹配不确定的链接进"⚑ 待确认"面板,带置信度与证据;可确认(挂到已有作品或作为新作品)或拒绝(拒绝过不复活) |
| FR-04 作者≠作品 | handle 只代表作者——同一作者可关联多部作品;平台 id(Steam/DLsite)才是强查重键 |
| FR-05 事实证据 | 发售日/价格/类型/Demo/语言每条事实都带**来源链接+抓取时间+状态**,抓取失败单独标红 |
| FR-06 发售状态 | 区分 未知/作者预告/商店待定/已确认/已延期/已发售,日期后移自动判"已延期",保留变更历史 |
| FR-07 价格 | Steam 按地区取价(货币+地区+原价/现价/折扣),DLsite 取円价;**不同地区价格分开展示不换算比较**;没价格显示"未标价"而非免费 |
| FR-08 类型 | 平台原始类型标签(Steam genres / DLsite 分类)单独展示,AI 归类紫色标签分开;"该作者其它作品"一键跳转 |
| FR-09 重要更新 | 自动识别 Demo/发售/延期/上架/定价/版本/汉化七类事件,普通帖归 `x_post` |
| FR-10 事件去重 | 同一事件在 X 与商店同时出现时合并为一条,证据列表列出全部来源,不重复提醒(14 天窗口) |
| FR-11 自定义提醒 | 按事件类型/来源全局开关 + 单作品 🔔 静音;普通 X 帖默认只进报告不弹窗 |
| FR-12 Demo 监测 | Steam `demos` 字段识别本体页入口与独立 Demo 页;DLsite `trial_download` 识别体験版;作者口头提及单独标注 |

### 浏览器扩展（REQUIREMENTS FR-17~20）

| 需求 | 功能 |
|---|---|
| FR-17 读选中标签页 | 只读**当前窗口已选中**的标签页;扩展无后台常驻,不点按钮绝不读取;无 `history` 权限 |
| FR-18 导入前预览 | 列标题/域名/网址/数量;可取消单页;自动排除批内重复与不支持站点(逐项标原因) |
| FR-19 一次提交 | 走 `/api/import` 建任务后台逐页处理,**轮询回传逐页结果**(已加入/已存在/待确认/失败+原因);"已提交"不等于"已添加" |
| FR-20 剪贴板备用 | 本地服务未启动时"复制勾选网址",粘到报告页批量添加框 |
| §7 本地接口收紧 | CORS 只回显白名单来源(不再 `*`);除 `/api/ping` 外全部要求 `X-Hyw-Token`;`llm_config`(含 key)同样受保护 |

## 快速开始

环境:Windows + Python 3(只用标准库,无需 pip 安装任何东西)。

```powershell
# 1. 添加关注(双击 或 命令行)
添加.cmd
#   粘贴链接回车, 例:
#   https://x.com/someone/status/123, https://x.com/another, https://store.steampowered.com/app/12345
#   支持: X帖子链接 / X裸主页 / Steam页 / DLsite页

# 2. 拉取更新(双击) -> 自动开 report.html
拉取.cmd
```

之后就是:**看报告 → 点星星排优先级 → 分类筛选快速浏览 → 不想看了点取消关注**。

## 浏览器扩展：导入选中标签页

浏览时用**中键/Ctrl/Shift** 把感兴趣的 X / Steam / DLsite 页面开成后台标签页,
攒一批后一次性导入,不用逐页复制网址。

```powershell
# 安装(Chrome/Edge 任一):
#   edge://extensions 或 chrome://extensions -> 打开"开发者模式" -> "加载解压缩的扩展"
#   选中本目录的 extension/ 文件夹
```

**使用流程**

1. 在标签栏用 **Ctrl+点击 / Shift+点击** 选中要导入的网页标签(只算当前窗口)。
2. 点扩展按钮 → 弹窗只列出**这 12 个选中页**(标题/域名/网址),不读其他标签、不扫历史。
3. 自动排除:批内重复、已关注、不支持的站点(逐项标注原因,可手动取消任意一页)。
4. 点"导入勾选的页面" → **逐页回传结果**:已加入 / 已存在 / 待确认 / 失败(含原因)。
   "已提交"≠"已添加",以下方逐页结果为准。
5. 本地服务没开时:弹窗会说明原因,点**"复制勾选网址"**一键复制,
   粘到报告页的"批量添加"框即可(备用通道)。

**安全(REQUIREMENTS §7)**:扩展权限只有 `tabs`(读选中页)、`clipboardWrite`(复制)、
`storage`(存 token),host 权限仅 `127.0.0.1:8790`;**没有后台常驻**——不点按钮绝不读取。
本地服务端:跨域只回显 白名单来源(扩展/报告页/回环),**除 `/api/ping` 外全部要求
`X-Hyw-Token`**(扩展首次使用填一次 `server_token.txt` 里的 token,报告页由拉取自动内嵌)。

## 报告页工具栏

- **＋ 批量添加链接**:大输入框,逗号/换行分隔,一次可贴几十个链接;后台执行,带进度日志查看
- **⚙ 模型 API**:填任意 OpenAI 兼容端点的 `Base URL / API Key / 模型名 / 额外 Header`,用于 AI 分类
  - **已预填 OpenCode Go**(`opencode.ai/zen/go/v1` + `x-opencode-session` 头;key 存本地凭据文件),面板里"测试连接"一键验证
  - 额外 Header 是给"网关要求自定义头"的服务准备的(JSON 格式),本地 Ollama 等留空即可
  - 配置存本地 `llm.json`(已被 .gitignore 排除,**永远不会提交到 Git**)
  - 没配置、或配置的端点连不上时,自动回退 DeepSeek(需要 `DEEPSEEK_API_KEY` 或本地凭据文件)

## 设计说明(为什么这么做)

- **为什么不用官方 API/关注**:X 官方 API 要钱,关注会污染推荐流;公开时间线 + 免登录读取是灰色但稳定的路子。
- **为什么是本地 HTML 而不是网站**:关注列表和封面图都是私人数据,只有本机跑才不需要操心隐私和服务费。
- **为什么点星星要一个本地 server**:静态 HTML 写不了文件,`server.py` 只监听 127.0.0.1,拉取结束自动带起,给报告页提供写回表格的通道。
- **首次拉取只建基线不报新**,避免入库当天弹一堆假更新。

## 已知边界

- X 拉取走 twitter-cli + 浏览器 cookie,cookie 过期需自行更新;批量拉太多账号会触发 X 的 429 限流(行间已有节流,仍失败就等几分钟重试)。
- DLsite 官方 RSS 已死,靠作品页 `販売日` 字段解析,页面改版需更新正则。
- 分类是 AI 判断,仅供参考,可直接改 `watchlist.csv` 的 `category` 列。
